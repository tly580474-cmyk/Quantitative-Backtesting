# 研究工作台视觉改造 · 第一批

日期：2026-08-31

## 本批范围

以 UI/UX 规范和多角色界面评审为依据，采用高信息密度的研究工作台风格，优先改造行情首页、策略工作室、回测结果，并推广共享组件至选股、因子研究和智研历史页。

| 界面 | 已实现 |
| --- | --- |
| 全局框架 | 明暗主题语义变量、紧凑导航、统一标题和面板、结构化加载骨架 |
| 市场数据 | 紧凑指数卡片；窄桌面默认 3 个，可展开其余；不改变保存的指数选择与顺序 |
| 策略工作室 | 中性面板、规则选中态；1440px 起保留三栏，较窄窗口用素材/属性抽屉；平板操作栏换行；修复手机标题区过大留白 |
| 回测结果 | 六项核心指标与权益走势同屏，其他指标可展开；紧凑历史队列和键盘打开；保留原有详细图表和交易列表 |
| 选股 | 简洁页头、压缩方法说明与日期区、降低逐行操作的视觉权重 |
| 因子研究 | 当前快照摘要折叠、非当前状态展开；空报告区提供打开最近报告入口；有报告后恢复分区拖拽 |
| 智研 | 会话/运行/报告上下文导航；手机历史卡片和分页；明确加载、空态和错误反馈；报告外框跟随主题 |

## 约束与语义

- 收益使用 A 股红正绿负；回撤采用独立风险色，不将状态成功/失败颜色等同于涨跌。
- 缺失指标显示破折号；合法无穷值显示 ∞；累计投入继续使用原净投入字段。
- 不修改回测计算、策略规则、交易与数据接口。本次实看仅导航及读取已有记录，没有发起研究、回测、交易或删除数据。
- 移动行情横滑、详情“走势/分析/资料”、自选和返回链路保留原实现。
- 未引入外部字体或新的 UI 依赖。

## 验证

- `npm test -- --reporter=dot`：181 个测试文件、1019 个测试全部通过。本批新增 9 个测试，覆盖指标语义、缺失值、媒体查询、上下文导航和历史卡片分页/加载态。
- `npm run build`：TypeScript 和生产构建通过。现有 Ant Design 大包告警仍在，未在此批进行依赖拆包。
- `git diff --check`：通过。测试中现有 MobileWatchlist 用例有 React `act(...)` 提示，不影响通过结果。
- 浏览器实看：1440px 明暗主题结果页、因子页和宽屏策略；1280px 行情、选股、策略；1024/768px 策略；390px 行情、自选、详情、策略、结果、报告历史；320px 运行历史。
- 实看修正：指数摘要继承的大最小高度、手机策略标题区的 flex 留白、768px 策略操作栏横向溢出。
- 1280px 行情指数区约 183px 高；1440px 策略两侧栏为 260/300px；移动关键页面没有整页横向溢出。行情卡片横滑和数据表内部横滚为有意保留的交互。
