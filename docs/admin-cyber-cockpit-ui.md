# 管理台 Cyber Cockpit 界面

设计依据：用户提供的 `admin-ui-proposals/proposal-3-cyber-cockpit.html`。
本次将参考风格应用到现有 React 管理台，而不是用静态样例替换业务页面。

- 悬浮顶部导航替代固定侧栏，窄屏显示两列导航，四个功能入口始终可达。
- 深蓝背景、紫青环境光、半透明面板、细描边；健康、警告、失败仍使用图标和文字共同表达。
- 总览首先展示系统状态和四个环形指标，再展示数据更新、备份及诊断。
- 环形指标明确标注堆内存、数据库连接、磁盘、会话池使用率；缺失比例显示“—”。
- 登录、配置编辑、重启确认沿用统一的玻璃面板与按钮样式。
- 保留原有接口、鉴权、配置回显、模块故障隔离和总览自动恢复；刷新文案对齐实际的 10/60 秒任务轮询。
- 提供跳转主内容链接、可见键盘焦点、图标按钮名称，以及减少动态效果的系统偏好支持。

修改文件：`admin/src/App.tsx`、`admin/src/styles.css`。
验证：管理台构建、27 项现有管理台测试，以及浏览器中的四个页面、弹窗与响应式布局。
浏览器预览使用本机临时示例接口，不读取或修改测试服务器的数据及配置。

部署方式：测试服务器 `192.168.2.218:8081` 仅更新前端源码、静态资源及本文档。
切换前备份现有文件，先安装带哈希的资源，最后原子替换 `index.html`；保留旧资源兼容已打开的页面。
部署后检查资源校验和、Nginx 读取权限和管理 API，同时确认后端进程及 `server/.env` 未发生变化。
具体备份位置和验收结果写入服务器部署目录中的 `deployment-result.json`。
