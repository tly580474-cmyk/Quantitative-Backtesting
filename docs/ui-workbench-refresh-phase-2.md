# 研究工作台视觉改造 · 第二批

日期：2026-08-31

## 范围与协作

延续第一批高信息密度工作台、明暗主题和语义色。使用 UI/UX 设计规范约束层级、对比度、触控目标和减少动效；不引入营销页式大留白或外部字体。

组长负责行情分析、共享组件整合、浏览器验收及回归；三个子代理分别负责数据管理、研究交易工作流、管理后台。完成后交叉审查异步状态、移动断点、语义和既有业务行为。

| 界面 | 已实现 |
| --- | --- |
| 行情分析 | 数据上下文页头；图层、周期、复权/导出操作分组；独立区间统计；桌面指标侧栏与窄屏抽屉；分钟行情加载、空态、失败重试及切换请求隔离 |
| 数据管理 | 指数/个股数据域导航；搜索与数据规模；紧凑记录及明确操作；手机数据域压缩；本地目录加载、失败、重试及慢响应保护 |
| 回测配置 | 参数分组、图表优先布局、可收起设置区及窄屏设置抽屉；统一进度和任务反馈；数据集加载失败与重试 |

## 语义与边界

- 沿用 A 股红正绿负，零收益为中性；运行成功/失败与金融涨跌使用不同语义。
- 不修改服务端、数据接口契约、回测计算、策略规则或交易撮合。异步调整仅涉及前端加载、错误、忙碌态及过期响应保护。
- 不新增 UI 依赖。按页样式避免覆盖功能原有移动布局；关键窄屏操作保持触控高度。
- 浏览器验收只导航、切换主题/视口、开关抽屉、读取已有数据和模拟账户记录。未发起回测、训练、委托、账户创建、导入、同步、删除、后台重启或配置保存。
- 未读取或填写真实后台凭据，认证与异常状态使用 mock API 测试。
