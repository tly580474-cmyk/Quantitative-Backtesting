# 移动布局与初步验收

## 设计边界

- 沿用现有 React、路由、状态及 API；桌面 JSX 与 `src/index.css` 保持原样。
- `useMobileLayout` 在 CSS 宽度小于 768px 时启用手机布局；主指针为触屏且宽度小于 1200px 时也启用，兼顾手机横屏和触屏平板。使用媒体查询范围语法，避免系统缩放产生的小数像素落入断点缝隙。
- `MobileAppLayout` 独立负责页头、底部五项导航、全部功能抽屉和页面滚动。手机样式限定在移动根类或 `body.mobile-layout-active` 下，离开手机布局即清理。
- 表格、指数卡、自选卡等只在区域内横向滚动；普通页面纵向滚动。智研、行情分析、回测及盘感训练使用剩余视口高度，由各自内容区处理滚动。
- 使用 `visualViewport` 调整可用高度，软键盘出现时隐藏底部导航；为安全区预留空间。主操作区采用约 44px 触控尺寸，输入字号 16px。

## 页面适配

| 页面 | 手机交互 |
| --- | --- |
| 行情/详情 | 指数横向卡片，报价优先，指标两列，图表与数据局部滚动；手机停用指数长按排序，保留桌面排序及图表交互 |
| 自选 | 顶部复用首页指数行情，同屏三个；列表三列双行显示名称/代码、价格/换手率、涨跌幅/自选后收益；点证券进入二级详情，返回保留自选入口；添加与管理收纳 |
| 因子研究 | 因子、参数、报告、任务四个视图；选择因子进入参数；保留表单状态，研究快照默认折叠 |
| 自动挖掘 | 新建任务、任务、候选分开；候选摘要与展开详情；人工批准弹窗共享桌面逻辑 |
| 回测 | 数据选择和运行入口置顶，参数进入全宽抽屉，图表占据剩余空间 |
| 回测结果 | 先浏览结果队列，再打开单项复盘，可返回队列 |
| 策略工作室 | 素材、属性进入抽屉；点击规则直接打开属性；抽屉可保存 |
| 智研 | 会话列表收纳，消息区和输入区分别布局，输入区不覆盖消息 |
| 模拟交易 | 账户记录与模拟委托分别显示，表单保持挂载 |
| 数据管理/选股 | 复用原有紧凑内容，接入手机页面滚动和局部表格滚动 |

日期范围弹窗在手机上固定于可见视口内，双月纵向排列并在弹窗内滚动。移动暗色模式覆盖了报告外框、快照和工作区抽屉背景。

## 验收范围与限制

这是浏览器尺寸模拟的初步界面验证，不能替代真实 iOS Safari / Android Chrome 上的软键盘、安全区和多指图表手势验收。键盘高度变化有单元测试；触屏横屏的媒体条件按代码实现，浏览器尺寸工具无法模拟主指针为触屏。

页面检查未启动真实研究、挖掘、AI 请求、发布或模拟下单，也未删除业务数据。盘感训练仅检查入口，未进行完整交易演练。业务提交路径继续沿用现有逻辑；新增批准测试仅使用 mock API。

代码只在 `codex/mobile-layout` 本地分支提交，不推送远程。

### 盘中与盘后刷新

手机自选列表及顶部指数共用一个刷新时钟。由后端上海时间和交易日历确认时段，不使用手机本地时区猜测开市。盘中每5秒启动一次刷新；上次请求未完成时不叠加请求，后台页面暂停，返回前台重新确认时段。轻量报价不再请求行业、上市日期等公司资料。桌面和首页原有轮询不受影响。

交易日09:30–11:30、13:00–15:00刷新；午休保留上午最后行情，13:00恢复。15:00补取收盘快照，15:05再对齐一次，随后停止报价轮询。盘前、周末与节假日读取最近已完成交易日的收盘数据，不把“昨收价”当作一整套收盘快照；缺失数据不填0。交易时段无法确认时保留现有显示、暂停自动报价，仅低频重试时段查询。

新增时钟测试覆盖5秒频率、服务端与设备时差、午休恢复、收盘及15:05对齐、休市手动刷新、日历失败恢复、后台暂停、请求重叠和卸载清理。

若交易日历缺少当天记录，使用指数行情源的实际交易时间及非零成交额确认开市；取数时间本身不作为证据，已标记休市的日历记录不会被覆盖。收盘快照优先接受有明确收盘时间的报价，否则用未复权的完整日线；当天收盘尚不可用时保留现有显示并提示失败，不退回昨日行情冒充今日收盘。实时请求最多等待4秒，四个独立请求槽持续处理列表；慢请求会跳过错过的刷新时隙，避免堆积，列表变更和离开页面会取消旧请求。

本轮复验：前端构建、后端类型检查通过，174个测试文件、1002项测试通过。390px和320px手机尺寸下已实看盘中提示及报价更新，无整页横向溢出；实际API校验显示股票和指数的收盘快照均取2026-08-28完整交易日，而非2026-08-31盘中数据。盘后、节假日及切换边界由模拟时钟和数据源测试验证，没有修改机器时间或真实交易日历。截图：`output/mobile-qa/watchlist-session-390.png`。
