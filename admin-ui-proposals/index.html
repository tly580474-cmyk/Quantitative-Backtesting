量化平台运维管理台 UI 重新设计方案

严格遵循“不改动现有功能与逻辑，仅重构 UI 视觉与交互”的原则，针对现有系统 4 大核心模块（运行总览、Agent 运维、问题诊断、配置与密钥）及各操作弹窗，交付三套完全独立的 HTML 交互原型。

PROPOSAL 01 RECOMMENDED
极简现代工程风
启发自 Linear、Vercel 与 Raycast 的极致克制美学。曜石黑背景配合 1px 精细修边与局部微光强调，极大减少视觉杂讯，带来专业纯粹的开发者级沉浸感。
  • 深曜石黑背景（#09090b）与优雅紫靛渐变
  • 微型药丸徽章与状态脉冲呼吸灯（Pill Dots）
  • 极致清晰的排版层级，模块间隔紧凑利落

PROPOSAL 03
未来数字驾驶舱
