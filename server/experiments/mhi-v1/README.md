# MHI v1 历史可行性实验

本目录是“大盘健康度指数”候选方案的离线实验，不接入生产接口或前端。

实验目标不是寻找最高未来收益，而是检查：MHI 较高时，未来 20 个交易日的最差收益、
下行半波动率和严重回撤概率是否系统性改善；同时检查它与 MSI 的重叠程度。

## 固定基线

- 趋势稳定度 30%：五个宽基指数的 20/60 日趋势与均线一致性。
- 参与持续度 25%：股票 MA20/MA60 覆盖率和申万一级行业 MA60 覆盖率。
- 风险韧性 30%：等权市场的下行半波动、60 日高点回撤和下跌共振。
- 流动性承载力 15%：Amihud 价格冲击、成交枯竭比例和成交集中度。
- 非自然有界指标使用过去 756 日滚动中位数和四分位距归一化，窗口排除当天；至少需要
  252 个既往观测。

股票收益使用研究快照的前复权价格。股票至少需要 120 个历史交易观测才进入横截面。
MSI 只构造用于相关性检查的历史代理值：由于快照没有完整历史涨跌停差，它只复现
MSI v2 的市场广度、涨跌强度和权重指数三项，并将三项权重重新归一化，不能视为正式
MSI v2 历史序列。

## 运行

从 `server` 目录执行：

```powershell
npm run duckdb -- pipeline --file ./experiments/mhi-v1/pipeline.json `
  --out-dir ../output/mhi-v1 --threads 8 --max-memory 8GB
```

输出包括逐日序列、十分位与固定健康区间验证、分时期稳定性、总体指标、组件相关性、
消融实验和典型压力期摘要。
