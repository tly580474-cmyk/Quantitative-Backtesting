# MHI v1 基线实验结果（2026-08-29）

## 结论

**部分证实，但不满足产品化条件。**

MHI v1 能识别已经进入脆弱状态的市场，并且与 MSI 代理指标保持较低重叠；但其风险分层
不够稳定，不能把它描述成可靠的市场转折预警或仓位择时指标。当前版本保留为研究基线，
不接入生产接口和前端。

## 样本

- 研究快照：`6ad0af8a-6e1a-4999-86d6-9db952f31dde-20260828015443`
- 评价区间：2007-01-04 至 2026-05-06
- 有效交易日：4,679
- 每日有效股票：1,097 至 5,421，均值 3,034
- 股票收益：前复权价格
- 归一化：过去 756 个交易日，排除当天，最少 252 个历史观测

评价结束早于原始数据结束日，是因为实验要求每个样本仍有完整的未来 60 日标签。

## 支持方案的证据

1. MHI 与 MSI 历史代理的相关系数为 0.211，二者没有退化为同一个指标。
2. 最低 MHI 十分位的未来 20 日严重回撤率为 37.39%，最高十分位为 20.56%，差
   16.84 个百分点。
3. 最低十分位的未来下行半波动率比最高十分位高 6.63 个百分点。
4. MHI 十分位与未来最差 20 日收益的秩相关为 0.745，整体方向符合“分数越高，
   未来承压越小”的定义。
5. 固定区间中，`MHI < 20` 的严重回撤率为 43.89%，`MHI >= 80` 为 9.52%。

## 反对直接产品化的证据

1. 分层不是严格单调。第 10 十分位的未来下行波动高于第 8 十分位；`60–80` 区间的
   严重回撤率为 22.30%，略高于 `40–60` 区间的 20.78%。强趋势阶段会同时带来高分
   和较高波动。
2. 2017–2021 子样本发生反转：最低十分位的严重回撤率反而比最高十分位低 21.54 个
   百分点，说明基线关系存在明显时期不稳定性。
3. 2015-06-12 的 MHI 为 79.25，但随后 20 个交易日等权市场最差收益为 -55.48%。
   它未能在泡沫峰值给出提前预警。
4. 2022-01-04 的 MHI 为 62.48，随后 20 日最差收益为 -11.35%。
5. 最低十分位未来 20/60 日平均收益仍为 +4.12%/+8.50%。低 MHI 经常出现在下跌已经
   发生之后，随后伴随反弹。因此 MHI 不能直接解释成“未来收益低”或卖出信号。
6. 消融实验中，去掉流动性组件后严重回撤率的首尾差从 16.84 提升至 20.25 个百分点；
   去掉参与度组件后提升至 21.97 个百分点。当前流动性和参与度设计稀释了风险识别。
7. 四个组件中，风险韧性与未来下行半波动的相关系数最强（-0.363）；流动性组件几乎
   没有有效方向（与未来最差收益相关 -0.004）。

## 真实性边界

- 该实验更接近“风险状态具有持续性”的验证，不是因果证明。
- MSI 使用历史代理：缺少完整的历史涨跌停差，只复现广度、涨跌强度和权重指数三项，
  并重新归一化权重。因此 0.211 是与 MSI 结构近似值的相关性，不是与正式 MSI v2
  历史序列的精确相关。
- 等权市场标签刻意反映多数股票的真实承压，但其波动和回撤会显著大于沪深300等权重
  指数，不能直接与指数点位跌幅对照。
- 股票至少拥有 120 个历史观测才进入横截面，降低了新股影响，但退市、停牌和历史名称
  状态仍需在下一轮做更严格的点时审计。

## 下一轮实验建议

1. 保留风险韧性作为核心；将趋势和参与度改为状态解释或交互项，不再简单线性加分。
2. 暂时移除当前流动性组件，再分别验证市值分层 Amihud、成交额覆盖率和成交集中度，
   避免组合后互相抵消。
3. 增加“过热/脆弱上涨”维度：高趋势、高参与但风险韧性下降时，不允许总分继续上升。
4. 采用滚动或逐时期锁定参数验证；下一版至少要在 2017–2021 子样本消除方向反转。
5. 将目标明确为未来回撤和下行波动的校准，不用未来平均收益调权。
