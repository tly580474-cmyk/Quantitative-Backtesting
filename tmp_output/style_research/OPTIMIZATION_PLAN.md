# 选股评分体系多风格优化计划

**编写时间**: 2026-07-26
**目标**: 在不修改项目现有代码的前提下，仅于 `tmp_output/style_research/` 内迭代多风格评分研究，最终产出一份综合研究报告。

---

## 一、现状评估（基线）

### 1.1 已完成的工作

- 定义 5 种投资风格（逆向抄底 / 价值投资 / 成长型 / 趋势型 / 短线打板）
- 实现 8 个新增风格专属因子（atr_20 / turtle_breakout_20 / ma_alignment_strength / limit_up_consecutive / kdj_j / bias_6 / intraday_strength / momentum_60d）
- 完成全样本（2021-07-25 ~ 2026-07-24，3,337 只股票 × ~1,124 交易日 ≈ 375 万条 K 线）评估
- 输出 `tmp_output/STYLE_COMPARISON_REPORT.md`

### 1.2 基线关键指标

| 风格 | 持有期 | 多空价差 | 单调性 | 方向一致率 | 状态 |
|------|--------|----------|--------|-----------|------|
| 逆向抄底 | 5d | +0.4265% | +0.8328 | 76.9% | ✅ 健康 |
| 价值投资 | 20d | -0.0713% | -0.3023 | 75.0% | ⚠️ 方向对但复合失效 |
| 成长型 | 20d | -1.6374% | -0.8862 | 0.0% | ❌ 主观方向与市场反向 |
| 趋势型 | 20d | -1.3197% | -0.7844 | 0.0% | ❌ 主观方向与市场反向 |
| 短线打板 | 1d | +0.0294% | +0.8249 | 0.0% | ⚠️ 方向反但极弱正 |

### 1.3 根因分析

**核心矛盾**：A 股短期-中期呈反转效应（mean reversion），但成长/趋势/短线风格主观设定"高动量 / 高突破 / 放量 = 高分"——与市场实际方向相反。

证据：
- `return_20d` 在所有风格中 `rank_ic` 均为负（-0.05 ~ -0.08），但成长/趋势/短线主观标 `HIGHER`
- `breakout_20d` 在所有风格中 `rank_ic` 均为负（-0.02 ~ -0.09），但主观标 `HIGHER`
- `volume_ratio`、`amount_20d_avg`、`momentum_60d` 同样呈反向

**次级问题**：
- 短线打板 horizon=1d 过短，复合评分统计意义有限
- 缺 dividend_yield / ROE / 营收增速等真基本面因子，价值/成长风格覆盖度不足
- 因子间高度相关（return_10d 与 return_20d 相关系数 > 0.85），权重被重复放大

## 二、优化方案（三阶段）

### 阶段 P0：方向校准与因子精选（必做）

**目标**：将所有风格的方向一致率提到 ≥ 60%，多空价差转正。

**步骤**：

1. **新增"数据驱动方向校准"机制**
   - 修改 `src/styles/style_scorer.py`：在 `evaluate()` 内对每个因子先计算 `avg_rank_ic`，按 sign 自动决定方向（IC>0 → HIGHER，IC<0 → LOWER）
   - 修改 `src/styles/definitions.py`：增加 `auto_calibrate: bool = False` 字段，对失败风格（成长/趋势/短线）开启
   - 对比校准前后的方向一致率、多空价差、单调性

2. **剔除弱因子（|rank_ic_ir| < 2.0）**
   - 修改 `style_scorer.py`：增加 `min_icir: float = 2.0` 参数
   - 输出每个风格精简后的因子清单
   - 重新计算复合评分，对比精简前后效果

3. **生成校准后报告**
   - 输出 `tmp_output/STYLE_COMPARISON_REPORT_V2.md`
   - 字段：风格 / 因子数（精简前→后）/ 方向一致率 / 多空价差 / 单调性 / 改进幅度

**预期产出**：
- ✅ 5 个风格的复合评分多空价差全部转正
- ✅ 方向一致率 ≥ 60%
- ✅ 报告 V2

---

### 阶段 P1：多周期 + 分年度评估（应做）

**目标**：找每种风格的最佳持有期，验证风格在不同市场环境下的稳定性。

**步骤**：

4. **多周期评估**
   - 短线打板：horizon = 1d / 3d / 5d / 10d
   - 价值投资 / 成长型 / 趋势型：horizon = 5d / 10d / 20d / 40d / 60d
   - 逆向抄底：horizon = 3d / 5d / 10d / 20d（基线对比）
   - 输出每种风格的最佳 horizon

5. **分年度评估**
   - 按 2021 / 2022 / 2023 / 2024 / 2025 年度切片
   - 计算每个风格在每个年度的多空价差与单调性
   - 输出"风格 × 年度"热力表，识别风格切换

6. **因子相关性分析**
   - 计算 35 个因子两两相关矩阵
   - 对 |corr| > 0.7 的因子对，保留 |ICIR| 更高者
   - 输出"因子去相关后"的精简清单

7. **生成多周期 + 分年度报告**
   - 输出 `tmp_output/STYLE_COMPARISON_REPORT_V3.md`
   - 字段：风格 / 最佳 horizon / 各年度 spread / 稳定性评分

**预期产出**：
- ✅ 每种风格有明确的最佳持有期
- ✅ 风格稳定性可量化（年度胜率）
- ✅ 报告 V3

---

### 阶段 P2：复合权重改进（可选）

**目标**：用更稳健的权重方法替代 |ICIR| 加权。

**步骤**：

8. **等权 vs ICIR 加权对比**
   - 同一风格下分别用两种权重计算复合评分
   - 对比多空价差、单调性、Sharpe（如有）

9. **因子中性化（市值中性化）**
   - 对每个因子按市值分组，组内 zscore 后再聚合
   - 评估中性化后 IC 的稳定性

10. **生成最终研究报告**
    - 输出 `tmp_output/STYLE_RESEARCH_FINAL.md`
    - 章节：
      1. 背景与方法论
      2. 基线问题诊断（V1）
      3. P0 方向校准验证（V2）
      4. P1 多周期与分年度（V3）
      5. P2 权重方法对比
      6. 五种风格最终配置（因子清单 / 方向 / 权重 / 最佳 horizon）
      7. 风险提示与改进路线
      8. 附录

**预期产出**：
- ✅ 最终研究报告（整合所有阶段结论）

## 五、风险与备选

| 风险 | 缓解 |
|------|------|
| P0 方向校准后某些风格因子数 < 3 | 退化到等权；或放宽阈值到 1.5 |
| P1 多周期评估耗时（35 因子 × 5 horizon） | 利用已有向量化实现，预期 < 10 分钟 |
| P2 因子中性化需引入 industry/market_cap 分组 | 复用 `candles_long` 中的 `industry` 字段 |
| A 股风格切换导致 P1 分年度不稳定 | 不强制要求每年都正，只观察稳定性 |

## 六、需要用户确认的关键决策

1. **是否同意"数据驱动方向"取代"主观方向"？**
   - 这是 P0 的核心，若不同意则整个优化方案无法启动。

2. **是否需要进入 P2 阶段？**
   - P2 涉及 ML 权重与中性化，工作量较大。可只做 P0+P1 然后整合报告。

3. **最终研究报告的输出位置？**
   - 默认 `tmp_output/STYLE_RESEARCH_FINAL.md`
   - 也可输出到 `doc/` 目录作为正式文档（但用户说"不碰项目现有代码"，所以默认放 tmp_output）。
