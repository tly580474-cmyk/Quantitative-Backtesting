## 4. M0 验收

### 已验证

- Strategy Experiment Spec、运行输入和结果使用严格 Schema；
- 规范化 JSON 与 hash 具备稳定测试；
- 能力清单由实际指标注册表与已发布因子版本自动构建；
- 当前只开放 A 股、日线、单标的和 `close_to_next_open`；
- 未知字段、未来成交语义和可执行代码不能绕过 Schema/语义校验；
- 多资产策略由独立 `MultiAssetPlan` 承载，不伪装成当前单标的能力。

### 结论

M0 通过。

## 5. M1 验收

### 已验证

- `SchemaRepairMiddleware` 只允许数字字符串转数字、固定输出类型补全和系统元数据；
- 修复保存前后 hash、字段 diff、操作类型和值，并写入审计日志；
- 不猜交易意图、不替换指标、不删除未知内容；
- 无法修复的输出返回 422 和确定性中文字段提示；
- 三栏界面真实展示“原始描述｜结构化抽取｜显式假设”；
- 五项假设未确认前，冻结按钮保持禁用；
- 真实模型冒烟成功：生成均线交叉策略，包含 1 个指标、买卖条件各 1 组、5 项显式假设
  和 Repair Audit；
- 单标的 Agent/UI 黄金样例、能力清单一致性和数据库分布式锁专项测试通过。

### 未满足

- 未找到不少于 200 条的模糊、冲突和完整策略人工标注集；
- 未找到字段级 precision/recall、首次通过率、确定性修复率、澄清率和人工确认修改率报告；
- 因此无法证明“修复后结构通过率不低于 95%”及自然语言语义质量目标。

### 结论

M1 工程门禁有条件通过，但正式质量验收不通过。补齐标注集和可重复评测报告前，不得把
M1 标记为完整完成。

## 6. M2 验收

### 已验证

- 确认后的策略创建不可变实验版本；
- 单标的执行复用 `compileAndValidate()` 与 `runBacktestAsync()`；
- Agent 路径和手工 UI 路径黄金样例结果完全一致；
- T 日收盘信号只能在 T+1 开盘成交；
- 规格、快照、参数、成本、结果与引擎版本保存 hash；
- 幂等键同输入复用，不同输入冲突；
- 运行终态使用 CAS；权威结果绑定不一致时拒绝关联。

### 结论

M2 通过。

## 7. M3 验收

### 已验证

- train/validation/locked-test 使用 purge/embargo 隔离；
- Walk-forward 和参数、成本、日期、延迟扰动已实现；
- 人工植入未来 offset 的测试被拒绝；
- 收盘信号同 bar 成交检查已实现；
- 锁定测试由 CAS、唯一 token 与数据库分布式锁保证原子性；
- 并发测试保证只有一个调用者获胜，获胜 token 重试幂等；
- 报告数值记录 `sourcePath` 与 `calculatorVersion`；
- 结构化 JSON 为权威制品，Markdown 可预览，HTML 可按需生成；
- PDF 不可用时明确失败，且不改变回测完成状态。

### 未满足

- 独立 PDF 渲染 Worker 尚未接入，当前返回 `PDF_RENDERER_UNAVAILABLE`；
- 回测结果复盘页尚未集中管理历史实验报告；
- 因此不满足实施计划中“建立按需 HTML/PDF 异步队列”的完整交付口径。

### 结论

M3 核心风险门禁通过，完整里程碑部分通过。现阶段应将 Markdown/HTML 作为正式报告
路径，不应承诺 PDF。

### 交易语义与治理

- 不使用当前成分股回填历史；
- Python 计算平面只能输出严格 `RebalancePlan`；
- TS 拒绝快照、日期、股票池、特征 hash 或权重异常计划；
- TS 逐日处理现金、持仓市值、权益、成本、换手、整手、容量、部分成交、停牌、涨跌停
  与公司行动；
- 调仓计划和执行结果原子写入，并保存 SHA-256；
- 数据库队列支持租约、恢复、最多三次退避、死信、取消与人工重试；
- `momentum_20` SQL 复用因子研究编译器；治理绑定检查发布状态、方向、快照与策略状态；
- 浏览器验收确认计划、运行状态、逐日账本、订单和两个下载制品可见。

### 结论

M4 v1 通过。以下不在完成范围：中证 500/全 A 股、通用多因子、行业中性、任意 Python、
Linux 容器沙箱、分布式消息中间件与多租户鉴权。

2. 验证 PDF 失败/拥堵不影响回测；
3. 在回测结果页集中查看历史实验报告及其制品状态。

### 后续里程碑

- M4 后续新增资产、数据字段和求解器版本（E1–E7 已完成）；
- M5 任意代码隔离、VectorBT 筛选与权威复算；
- 生产多租户鉴权和消息中间件。

## 11. 最终签署意见

项目可以继续用于受约束的单标的实验、M3 核心稳健性验证和 M4 v1 沪深 300 研究，不应
阻断后续开发。但在补齐 M1 量化质量证据和 M3 PDF/历史报告之前，项目状态必须保持
“有条件通过”，不得对外宣称 M0–M4 全部完成。
