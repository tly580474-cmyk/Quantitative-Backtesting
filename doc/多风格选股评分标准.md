# 多风格选股评分标准

本文档记录当前选股评分系统已经落地的五类投资风格、因子权重、评分方向、推荐周期及统一风控规则。

> 评分用于候选股票比较和研究，不构成投资建议或收益承诺。

## 一、风格总览

| 风格 | 风险等级 | 推荐观察/持有期 | 核心逻辑 | 大盘比较方向 |
| --- | --- | ---: | --- | --- |
| 价值投资 | 稳健 | 60 日 | 高股息、低估值、高 ROE、低波动 | 相对沪深 300 越强越好 |
| 成长型 | 稳中求进 | 60 日 | 业绩增长、盈利质量、量价与趋势确认 | 相对沪深 300 越强越好 |
| 逆向抄底 | 进取 | 20 日 | 超跌、低 RSI、缩量、反转修复 | 相对沪深 300 越弱，反转空间越大 |
| 趋势型 | 进取 | 60 日 | 均线多头、突破、趋势延续 | 相对沪深 300 越强越好 |
| 短线打板 | 激进 | 10 日 | 连板、突破、放量、日内强势 | 相对沪深 300 越强越好 |

每种风格的因子总权重均为 100%。

## 二、价值投资评分

| 指标 | 权重 | 评分方向或映射规则 |
| --- | ---: | --- |
| 近 12 个月股息率 | 22% | 最高权重；5% 及以上接近满分，使用近 12 个月已实施现金分红合计 ÷ 当前股价 |
| ROE | 15% | 越高越好；约 5% 为低分，20% 附近接近满分 |
| PE(TTM) | 13% | 正 PE 越低越好；约 8 倍接近满分，45 倍附近降至低分；负 PE 不获得低估值高分 |
| PB | 12% | 越低越好；约 0.8 倍接近满分，6 倍以上为低分 |
| 相对沪深 300 的 60 日强弱 | 12% | 跑赢越多越好；跑赢 10 个百分点接近满分 |
| 20 日回撤控制 | 10% | 距离 20 日阶段高点越近越好 |
| 总市值稳健度 | 8% | 大市值获得更高稳健度分数，使用对数映射，降低极端市值差异的影响 |
| 20 日年化波动率 | 8% | 越低越好 |

价值评分必须展示股息率。股息率缺失时保留 22% 权重，以中性分占位并降低数据覆盖率，不得静默删除。

## 三、成长型评分

| 指标 | 权重 | 评分方向或映射规则 |
| --- | ---: | --- |
| 净利润同比增长 | 20% | 越高越好，重点验证利润增长是否真实兑现 |
| 营收同比增长 | 18% | 越高越好，避免只依赖利润端一次性变化 |
| 相对沪深 300 的 60 日强弱 | 15% | 跑赢大盘越多越好 |
| 60 日收益率 | 12% | 越高越好，作为市场对成长预期的确认 |
| ROE 质量 | 10% | 越高越好，防止只有规模增长而没有资本回报 |
| 当日量比 | 8% | 越高越好，作为资金关注度的辅助确认 |
| MA60 的 5 日斜率 | 7% | 均线向上越明显越好 |
| 20 日突破强度 | 5% | 突破前 20 日高点越明显越好 |
| 市值承载力 | 5% | 使用对数映射，降低极小市值炒作对评分的影响 |

成长型不再使用“高 PE 等于高成长”的代理逻辑，优先使用真实营收增长、净利润增长和 ROE。

## 四、逆向抄底评分

| 指标 | 权重 | 评分方向或映射规则 |
| --- | ---: | --- |
| 20 日突破强度 | 15% | 越低越好，偏好尚未过度突破或已经明显回落的标的 |
| 相对沪深 300 的 20 日强弱 | 12% | 当前越弱，潜在反转空间越大 |
| 20 日收益率 | 12% | 越低越好，偏好阶段超跌 |
| 换手率 | 12% | 越低越好，避免高换手情绪炒作 |
| RSI(14) | 11% | 越低越好，识别超卖状态 |
| 近 5 日/前 15 日波幅比 | 11% | 越高越好，用于识别波动释放后的反转机会 |
| 当日量比 | 9% | 越低越好，偏好缩量回调而非放量下跌 |
| MA60 的 5 日斜率 | 9% | 越低越好，体现逆向反转逻辑 |
| 价格相对 MA20 | 9% | 越低越好，识别价格偏离均线后的修复空间 |

该风格沿用全市场回测验证的反转方向，不适合作为追涨评分。

## 五、趋势型评分

| 指标 | 权重 | 评分方向或映射规则 |
| --- | ---: | --- |
| MA5/MA10/MA20/MA60 多头排列 | 18% | 满足的多头排列层级越多越好 |
| 相对沪深 300 的 60 日强弱 | 15% | 跑赢大盘越多越好 |
| 60 日收益率 | 15% | 越高越好，确认中期趋势延续 |
| 20 日突破强度 | 12% | 突破前期高点越明显越好 |
| MA60 的 5 日斜率 | 10% | 均线向上越明显越好 |
| 价格相对 MA20 | 10% | 站上 MA20 且距离适度扩大更优 |
| ATR(20)/价格 | 8% | 越低越好，偏好趋势清晰而非无序剧烈波动 |
| 20 日收益率 | 7% | 越高越好，确认短中期趋势一致 |
| 当日量比 | 5% | 越高越好，作为资金参与度确认 |

## 六、短线打板评分

| 指标 | 权重 | 评分方向或映射规则 |
| --- | ---: | --- |
| 连续涨停天数 | 20% | 连板越多越高，3 板附近达到最高映射分 |
| 20 日突破强度 | 12% | 越高越好 |
| 当日量比 | 12% | 越高越好，确认资金参与度 |
| BIAS(6) | 10% | 约 6% 附近较优；过低代表不强，过高代表追涨风险 |
| KDJ-J | 10% | 约 85 附近较优；过低不够强，过高可能过热 |
| 日内收盘强度 | 10% | 收盘越靠近日内高位越好 |
| 10 日收益率 | 10% | 越高越好 |
| 相对沪深 300 的 20 日强弱 | 8% | 跑赢越多越好 |
| RSI(14) 接力区 | 8% | 约 72 附近较优，过低不强、过高防止极端过热 |

短线打板的 1 日评分已在研究中被证伪，当前采用 10 日退化方案，并保留激进风险等级。

### 涨停识别阈值

| 板块 | 识别阈值 |
| --- | ---: |
| 沪深主板 | 涨幅 ≥ 9.5% |
| 创业板、科创板 | 涨幅 ≥ 19.5% |
| 北交所 | 涨幅 ≥ 29.5% |

阈值比交易所正式涨停比例低 0.5 个百分点，用于容纳价格取整和行情数据精度误差。

## 七、统一评分规则

| 项目 | 统一规则 |
| --- | --- |
| 风格总分 | 每种风格总权重固定为 100% |
| 技术因子口径 | 使用最近最多 252 个交易日的单股历史分位 |
| 大盘基准 | 统一使用沪深 300 |
| 相对强弱映射 | 相对收益每跑赢 1 个百分点增加约 5 分，每跑输 1 个百分点减少约 5 分，最终限制在 0–100 分 |
| 财务指标口径 | 使用当前可获得的最新财务指标和近 12 个月已实施现金分红 |
| 缺失因子 | 按中性 50 分占位，不把缺失权重重新分配给其他因子 |
| 数据覆盖率 | 按实际可用因子的权重合计计算 |
| 流动性过滤 | 20 日均成交额低于 1000 万元时，最终得分最高限制为 39 分 |
| 页面即时评分 | 单股时间序列分位和财务规则映射的低延迟代理，不等同于全市场横截面回测分数 |

## 八、评分档位

| 得分 | 档位 | 含义 |
| ---: | --- | --- |
| 80–100 | 核心优选 | 当前风格下证据较强，可进入重点候选池 |
| 60–79 | 持有观察 | 风格适配度较高，可继续观察或持有 |
| 40–59 | 中性观察 | 证据不足或存在分歧，不优先新增仓位 |
| 0–39 | 回避冷却 | 风格适配度偏低，或已触发流动性硬过滤 |

## 九、使用限制

1. 不同风格的分数代表不同投资逻辑，不应直接把多个风格分数简单相加。
2. 价值、成长、趋势评分建议按约 60 个交易日观察；逆向抄底约 20 日；短线打板约 10 日。
3. 数据覆盖率不足时，需要先确认缺失的是财务数据、股息率还是基准行情，再解释最终分数。
4. 评分只负责候选排序，最终决策仍需结合市场环境、个股相对强弱、消息面和统一风险规则。
